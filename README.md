# Tracey Kadenyi — Portfolio Website

A personal portfolio website built with Next.js 14 (App Router), TypeScript, and Tailwind CSS v4. Features Three.js animations, a Medium blog integration, dark/light mode, and a fully responsive layout.

<!-- **Live:** [tracey-kadenyi.vercel.app](https://tracey-kadenyi.vercel.app) -->

---

## Tech Stack

| Category | Technology |
|---|---|
| Framework | Next.js 14 (App Router) |
| Language | TypeScript |
| Styling | Tailwind CSS v4 |
| 3D / Animation | Three.js, `@react-three/fiber` |
| Animations | Framer Motion |
| Theme | `next-themes` |
| Icons | Lucide React |
| Blog | Medium RSS via `/api/blog` proxy route |
| Deployment | Vercel |
